Sales Performance Dashboard — Excel
Project Overview

An interactive Excel dashboard designed to analyze sales performance, profitability, order volume, and profit margins across different regions, product categories, and sales channels.

Tools Used
Microsoft Excel
Pivot Tables and Pivot Charts
Excel Slicers
Data Analysis and Visualization
Key Performance Indicators (KPIs)
Total Sales
Total Profit
Total Orders
Profit Margin
Dashboard Features
Monthly sales and profit trend analysis
Region-wise sales comparison
Category-wise profit analysis
Interactive filters for Channel, Region, and Category
Dataset Fields

Order ID, Order Date, Region, Salesperson, Category, Product, Units, Unit Price, Sales, Cost, Profit, Channel, and Profit Margin.

Files Included
Sales_Performance_Dashboard.xlsx — Excel workbook containing the data, analysis, and dashboard.
dashboard.png — Dashboard preview.
How to Use
Download the Excel workbook.
Open it in Microsoft Excel.
Navigate to the Dashboard sheet.
Use the available slicers to explore sales performance.
Note

This project is intended for learning and portfolio demonstration.
